# Synthetic sample data

Every file in this directory is **fictional**. The names, addresses, phone
numbers, card numbers, account identifiers, hostnames, and credentials were
invented to exercise the scanner and its detectors. None of them belong to a
real person or system, and none of the credentials grant access to anything.

This directory exists so a new user can run a scan immediately and see:

- file categories and metadata;
- sensitive-data findings across PII, financial, credentials, cloud, and
  infrastructure categories;
- dashboard charts, search filters, and report downloads.

Use it as a scan target:

```
examples/sample-data
```

Do not replace these files with real data. If you need a more realistic corpus,
generate it yourself and keep it outside the repository.
