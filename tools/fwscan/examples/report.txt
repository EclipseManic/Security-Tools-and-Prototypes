 3. SOURCE REPUTATION ASSUMPTION
------------------------------------------------------------------------------
 No reputation feed is consulted. Attribution rests on these assumptions,
 stated so they can be argued with:

 R1. The SRC field is the true originator of the traffic.
     because   : It is the only identity a deny log carries.
     breaks if : NAT, CGNAT, a forward proxy, cloud egress or a VPN concentrator rewrites the source.
     effect    : Every finding becomes an attribution to a middlebox, not a host.
     validate  : Correlate SRC against NAT translation logs before any block or takedown action.

 R2. No reputation feed is consulted; reputation is derived from address space and observed behaviour only.
     because   : A bundled blocklist goes stale and silently decides attribution.
     breaks if : You need prior badness for a first-seen address, or you need to clear an address that a feed already flagged.
     effect    : A known-bad scanner on its first visit here scores the same as any noisy host; a compromised friendly host is never pre-cleared.
     validate  : Join SRC against your own threat-intel and asset inventory, then re-run with --known-bad / --internal.

 R3. Internal RFC 1918 sources are lower risk than external ones.
     because   : Most internal deny bursts are broken jobs, not intrusions.
     breaks if : The internal host is already compromised and is scanning east-west, which is the exact behaviour this assumption de-prioritises.
     effect    : Lateral movement from an internal host can be ranked below a noisy internet scanner.
     validate  : Treat internal high-score findings as containment candidates, not as noise; check EDR/AV history for the host.

 R4. One firewall's view equals the whole network's view.
     because   : Only one deny log was supplied.
     breaks if : Traffic is denied (or permitted) on a path this sensor does not see: east-west segments, cloud VPC, host firewalls.
     effect    : Scan volume is under-counted and a scan that succeeds elsewhere looks like a scan that stopped.
     validate  : Aggregate every deny source you have; compare per-sensor counts.
