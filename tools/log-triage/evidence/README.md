- `01_run_command.png` — end-to-end CLI run and console summary.
- `02_output.png` — rendered Markdown triage report.

The PNGs are renders of the actual console and output text produced by the tool
on `sample_input/triage_sample.log`. They are generated from the captured run
rather than a screenshot utility, so the text matches what the tool prints.
